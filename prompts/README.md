# Prompts

- [write.md](write.md): instructions for agents that write F#, to paste into `AGENTS.md`, `CLAUDE.md`, or your tool's instruction file.
- [review.md](review.md): the reviewer prompt for one rule or a small group of related rules.
- [test-rule.md](test-rule.md): checks whether a rule leads a model to the expected verdict on small synthetic cases.

The prompts hold the generic instructions, so the rule files do not repeat them.
